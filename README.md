# JavaScript Object Practice

Practice problems for learning and working with JavaScript Objects.

## Task-1: Access Object Property

Access the `golden rod` color value in output.

```js
const colors = {
    red: "#ff0000",
    green: "#00ff00",
    blue: "#0000ff",
    "golden rod": "#daa520"
};
```

## Task-4: Count Number of Properties

Count the `number of properties`.

### Input

```js
let student = {
    name: "Ariana Grande",
    age: 21,
    city: "Gaibandha",
    isStudent: true
};
```

### Output

```text
4
```

## Task-5: Loop Through an Object

### Hard

Loop through an object and print the key-value pairs with their `types`.

### Input

```js
let myObject = {
    name: "John Doe",
    age: 25,
    city: "Example City",
    isStudent: true
};
```

### Output

```text
key: name | type: string
key: age | type: number
key: city | type: string
key: isStudent | type: boolean
```
